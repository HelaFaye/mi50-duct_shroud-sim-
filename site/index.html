ENGINEERING NOTE

Fan ratings are not installed airflow

The shroud geometry alone cannot certify 300 W cooling. We still need fan P–Q curves, heatsink pressure drop, leakage estimates, and sustained GPU temperature testing.

Read airflow design notes
MODEL ACCURACY

Reference fit remains provisional

The uploaded source mesh has defects and the exact heatsink/PCB mounting interfaces still need physical verification. Do not treat this reconstruction as a validated drop-in replacement yet.

Read geometry roadmap
HARDWARE EVIDENCE

16GB and 32GB board profiles

AMD publishes a common external envelope, but internal cooler geometry is not yet verified across both variants. Review evidence status and the physical measurement guide.

Read MI50 mechanical reference
