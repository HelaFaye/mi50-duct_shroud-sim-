MI50 repository-integrity and CI overlay

Apply from the root of the existing mi50-duct_shroud-sim checkout:

  unzip -o ~/Downloads/mi50-repository-integrity-overlay.zip -d .

Verify the overlay payload and review the patch/new files before committing:

  sha256sum -c OVERLAY_SHA256SUMS

  git status --short
  git diff --check
  git diff -- README.md
  sed -n '1,240p' docs/REPOSITORY_STATUS.md
  sed -n '1,160p' .github/workflows/tests.yml

Run the same suite locally:

  python3 -m compileall -q analysis scripts tests
  python3 -m unittest discover -s tests -v

Expected local suite: 21 tests. GitHub Actions will run the same suite on
Python 3.10, 3.12, and 3.14 for pushes, pull requests, and manual dispatch.

The manifest is named OVERLAY_SHA256SUMS so the repository's existing
SHA256SUMS file (which covers the earlier solver overlay) is preserved.

This overlay does not restore CAD/STL/CFD files, change the solver, invent
measurement uncertainty values, or modify the measured system-curve template.
It corrects the README's inventory, records the audited repository boundary,
and adds automated CI for the checked-in Python suite.
